
# SpendWise Dashboard

## Project Description
SpendWise is a static personal finance dashboard built using HTML and CSS. It displays sample financial summaries and spending categories in a clean, responsive layout.

## Features
- Sidebar navigation menu
- Dashboard header and user profile
- Financial summary cards for budget, spending, and remaining balance
- Six spending categories: Food, Transport, Rent, Entertainment, Savings, and Utilities
- Responsive layout for smaller screens
- CSS Grid and Flexbox
- CSS custom properties for consistent theming
- Hover and keyboard-focus effects
- Dark theme using the user's system color preference

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media queries
- CSS custom properties

## Project Files
- `index.html` - Contains the dashboard structure and sample financial content.
- `style.css` - Contains the theme, layout, responsive styles, and animations.
- `README.md` - Explains the project and its features.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Resize the browser to test the responsive layout.

## Layout Explanation
CSS Grid creates the main two-column dashboard layout and the category card grid. Flexbox arranges navigation links, the header, and the summary cards. A media query changes the dashboard into a single-column layout on screens narrower than 768 pixels.

CSS variables defined in `:root` control the colors. Hover and focus transitions provide subtle visual feedback for navigation links and category cards.
